# Third-party code bundled in plugin-permissions

`src/backend/pi/plugin-permissions/dist/plugin-permissions.js` (compiled into OpenGhost as a Qt
resource and run inside Pi) bundles the npm packages below, and ships the two
WebAssembly grammars `web-tree-sitter.wasm` and `tree-sitter-bash.wasm` beside it.
Each package's license follows, verbatim.
