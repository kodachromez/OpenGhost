# Frozen frontend reference

`openghost/` is the unchanged tracked tree of the dissected OpenGhost 1.3
frontend at commit `177ba954d0ddc7b47dd0526b11f98b517c1735ff`.

It is the visual and behavior specification for the native frontend. Its
Electron/JavaScript source, assets, documentation and tests are retained only
for comparison. They are not built, loaded or installed by the root Qt project.
Do not use Ghosty's custom appearance/features as the reference.
